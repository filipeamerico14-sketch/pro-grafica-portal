# PRO GRÁFICA — Portal

Portal web para gestão de pedidos de uma gráfica (impressão, design, etc.).

## Funcionalidades

- **Clientes**: enviar pedidos, acompanhar estado, ver pagamentos e documentos
- **Funcionários**: gerir pedidos e atendimento
- **Administrador**: equipa, relatórios, publicidade, configurações e pagamentos

Os dados ficam guardados no `localStorage` do navegador (demonstração offline).

## Como usar

1. Descarrega ou clona este repositório
2. Abre o ficheiro `index.html` no navegador  
   (ou usa um servidor local simples, por exemplo: `npx serve .`)

## Estrutura do projeto

```
pro-grafica-portal/
├── index.html      # Página principal
├── styles.css      # Estilos
├── app.js          # Lógica da aplicação
├── data.json       # Configuração e serviços padrão
└── README.md
```

## Notas

- Esta é uma **versão de demonstração**. Os ficheiros enviados e os dados não são guardados num servidor.
- Para produção, será necessário um backend (base de dados, autenticação real, armazenamento de ficheiros, etc.).
